[ 01 / Features ]

      
Small tool. Sharp edges.

      
Everything grep users reach for, plus a filter language that understands the line, its number and the groups your regex captured.


      

        

          01
          
Text or regex

          
Plain text ignores case. Wrap a pattern in slashes for a regex, with named groups you can reuse.

          --match '/id=(?<id>\w+)/'
        

        

          02
          
Semantic filters

          
Keep a match only if an expression holds. Repeat the flag and every clause must pass. No eval.

          --where 'line.length > 120'
        

        

          03
          
Count by group

          
Get how many matches there are per value of a group, most frequent first. Replaces a pipe of sort and uniq.

          --count-by level
        

        

          04
          
JSON output

          
One JSON object per match, with the line number, the text and the groups. Ready for jq and scripts.

          --emit json
        

        

          05
          
Pipes and scripts

          
Reads files or standard input. Exit code 0 matched, 1 nothing matched, 2 error. Stops when the pipe closes.

          tail -f app.log | mgrep …
        

        

          06
          
Native executable

          
Written in Clojure and built with GraalVM. Download one file, install it, run it. Uninstall script included.

          install · uninstall
        

      

    

  


  
  

    

      
[ 02 / Examples ]

      
Learn it in four commands.

      
The general form is mgrep <file> --match <pattern> [--where <expression>]… Leave out the file to read from a pipe. Every example below uses this log.


      

        
app.log


2026-10-31 10:00:01 INFO  server started port=8080
2026-10-31 10:00:05 WARN  slow query took=1200ms
2026-10-31 10:00:09 ERROR status=503 upstream timeout
2026-10-31 10:00:12 INFO  GET /health status=200
2026-10-31 10:00:15 ERROR status=404 route not found
2026-10-31 10:00:21 ERROR status=500 db connection lost

      


      

        

          
01 · Use a number from the line


mgrep app.log --match '/status=(?<code>\d+)/' --where 'group("code") >= 500'
2026-10-31 10:00:09 ERROR status=503 upstream timeout
2026-10-31 10:00:21 ERROR status=500 db connection lost

          
Name a group in the regex, read it with group("code"). Numeric text compares as a number.

        


        

          
02 · Combine filters


mgrep app.log --match ERROR \
  --where 'line.number > 3' \
  --where 'line.contains("not found")'
2026-10-31 10:00:15 ERROR status=404 route not found

          
Repeat --where. Every clause has to hold.

        


        

          
03 · Count by a value


mgrep app.log --match '/(?<level>INFO|WARN|ERROR)/' --count-by level
3 ERROR
2 INFO
1 WARN

          
Most frequent first. Filters still apply to what gets counted.

        


        

          
04 · Get JSON


mgrep app.log --match '/status=(?<code>\d+)/' --where 'group("code") >= 500' --emit json
{"line":3,"content":"2026-10-31 10:00:09 ERROR status=503 upstream timeout","groups":{"code":"503"}}
{"line":6,"content":"2026-10-31 10:00:21 ERROR status=500 db connection lost","groups":{"code":"500"}}

          
One object per line, so tools like jq read it directly.

        

      

    

  


  
  

    

      
[ 03 / Install ]

      
Download. Run. Done.

      
Grab the archive for your system from the latest release. Each one ships with an install and an uninstall script.


      

        

          
Windows 11 / 10

          
Double-click

          
    
            
  1. Extract borba-mgrep-<version>-windows-x64.zip.
    2. 
            
  2. Double-click install. If Windows warns about an unrecognized app, choose More info, then Run anyway.
    3. 
            
  3. Open a new terminal and run mgrep --help.
    4. 
          

          
To remove it, double-click uninstall in the same folder.

        

        

          
Linux x64

          
Three lines

          


tar -xzf borba-mgrep-<version>-linux-x64.tar.gz
cd borba-mgrep-<version>-linux-x64
./install.sh

          

          
Installs to ~/.local/bin. Run ./uninstall.sh to remove it.

        

      

    

  


  
  

    

      
[ 04 / Reference ]

      
Everything on one screen.

      
Run mgrep --help to see it in your terminal.


      

        

          
Patterns

          

            
errorPlain text. Ignores case by default.

            
/err(or|warn)/Regex between slashes. Respects case.

            
/id=(?<id>\w+)/Regex with a named group.

            
--casesensitive or insensitive.

          

        

        

          
Where expressions

          

            
line.lengthCharacters in the line.

            
line.number1-based line number.

            
line.contentThe line text.

            
line.contains("x")Also startswith, endswith.

            
group("name")A named regex group.

            
> < >= <= == !=Compare. Join with and or not ( ).

          

        

        

          
Options and exit codes

          

            
--where EXPRRepeatable. All must hold.

            
--count-by NAMECount per group value.

            
--emit jsonOne JSON object per match.

            
0A line matched.

            
1Nothing matched.

            
2Bad usage or an error.
